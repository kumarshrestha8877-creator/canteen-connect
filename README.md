# Canteen Connect 🍽️
> **Tagline:** *Order Smart. Eat Fresh. Skip the Queue.*

An attractive, modern, and simple frontend web application for college/school canteen management.

## 🚀 How to Run

No complicated installation or command-line setup is needed!

1. Open File Explorer and navigate to:
   ```
   C:\Users\kumar\.gemini\antigravity\scratch\canteen-connect
   ```
2. Double-click **`index.html`** to launch it directly in your default browser (Chrome, Edge, Firefox, Safari).

### Alternative (Using a local server)
If you have Node or Python installed and prefer running via localhost:
```bash
npx serve .
# or
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 📁 Key Files
- `index.html`: The main web page.
- `css/styles.css`: Custom styling, ticket stub effects, and animations.
- `js/data.js`: Menu catalog, categories, items, and promo codes.
- `js/app.js`: Application logic (cart, filters, token generator, simulation).
- `PROJECT_REPORT.md`: Project documentation, system architecture, and viva notes.
